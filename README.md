# پروژه اولیه SaaS نام سایت

یک نمونه اولیه‌ی فرانت‌اند با HTML، CSS و JavaScript خام؛ بدون React یا کتابخانه‌های خارجی جاوااسکریپت.

## اجرا

فایل `index.html` را در مرورگر باز کنید. برای تجربه بهتر می‌توانید از افزونه Live Server در VS Code استفاده کنید.

## صفحات

- `index.html`: صفحه اصلی و مودال ورود
- `detail.html`: جزئیات سرویس و فرم ۵ فیلدی
- `dashboard.html`: پنل کاربری، درخواست‌ها و بخش دانلودها
- `css/style.css`: تمام استایل‌ها و ریسپانسیو
- `js/app.js`: مودال، منو، پیام‌ها و ذخیره‌سازی محلی
- `js/login.js`: رفتار ورود نمایشی
- `js/detail.js`: اعتبارسنجی فرم، جداکننده سه‌رقمی و تبدیل عدد به حروف
- `js/dashboard.js`: نمایش درخواست‌های ثبت‌شده

## پنج فیلد فرم

1. نام و نام خانام سایتدگی (متن)
2. شماره موبایل (عدد)
3. تاریخ شروع مدنظر (تاریخ)
4. بودجه مدنظر (عدد با جداکننده سه‌رقمی و نمایش حروف)
5. تعداد کاربران (عدد با جداکننده سه‌رقمی و نمایش حروف)

## نکته مهم برای ارائه به استاد

این نسخه فعلاً نمایشی است؛ ورود واقعی، احراز هویت، ثبت امن اطلاعات و دانلودها باید بعداً از طریق API انجام شود. `localStorage` فقط برای نمونه اولیه است و جایگزین بک‌اند یا احراز هویت امن نیست. فونت از Google Fonts بارگیری می‌شود؛ در صورت نیاز به اجرای کاملاً آفلاین، فونت محلی اضافه کنید.
